# LS Jabones

Aplicación web de catálogo, pedidos y reservas para un emprendimiento real de jabones artesanales fabricados a pedido (sin stock), con notificación automática de pedidos por WhatsApp y agente de marketing reactivo.

## Stack

- Frontend: React 18 + Vite + TypeScript + Tailwind CSS.
- Backend: Node.js + Express + TypeScript.
- Base de datos: **PostgreSQL** (desvío documentado respecto al stack Mongo del brief original — ver `docs/analisis-mejoras.md`).
- Integraciones: Meta WhatsApp Cloud API, Mercado Pago Checkout Pro.
